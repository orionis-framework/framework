class MediaTypeRegistry(IMediaTypeRegistry): (source)

Constructor: MediaTypeRegistry(parsers)

View In Hierarchy

Map lowercased media-type strings to synchronous BodyParser callables.

multipart/form-data is intentionally absent: multipart parsing requires a streaming body rather than pre-buffered bytes. Request.payload() handles that case explicitly before consulting this registry.
