class FailureHandling: (source)

View In Hierarchy

Own logging and optional presentation for one observed incident.

The runtime completes logging after the application hook returns. The protocol owner may then request presentation with its live request. Keep this object local to the operation; immutable receipts contain only status.

async def complete(self): (source) ¶

Execute the deferred logging action at most once.

Serialize concurrent calls and preserve failures for later callers. Restore the original traceback before re-raising a retained error so repeated callers do not accumulate one another's stack frames. Set reported after successful logging; skip logging if no action is configured or a previous call completed successfully.

Returns
NoneNo return value.
Raises
RuntimeErrorIf the logging action recursively waits for its own completion.
BaseExceptionIf execution is cancelled, logging fails, or a retained failure is re-raised.
async def present(self, *, flow: str, request: object | None = None) -> object: (source) ¶

Execute deferred presentation at most once and cache its result.

Serialize concurrent calls and preserve failures for later callers. Retained errors keep their identity, cause, and original traceback without accumulating the frames of previous consumers.
