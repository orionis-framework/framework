class HTTPBodyLimits(BaseEntity): (source)

View In Hierarchy

Configure finite request, buffering, multipart and concurrency budgets.

Read environment defaults when each instance is created. Explicit constructor values take precedence and every budget remains immutable after validation.

Method __post_init__ Validate finite byte budgets and nonnegative multipart counts.
Instance Variable max_body_size Maximum transport bytes consumed for one request, including framing. Defaults to 16 MiB from HTTP_MAX_BODY_SIZE.
Instance Variable max_buffer_size Maximum bytes materialized by body(), JSON and other buffered parsers. Defaults to 2 MiB from HTTP_MAX_BUFFER_SIZE.
Instance Variable max_concurrent_requests Maximum active HTTP requests per kernel, including response delivery. Defaults to 128 from HTTP_MAX_CONCURRENT_REQUESTS.
Instance Variable max_field_size Maximum bytes of one multipart text field before decoding. Defaults to 1 MiB from HTTP_MAX_FIELD_SIZE.
Instance Variable max_fields Maximum multipart text field count; zero rejects all text fields. Defaults to 128 from HTTP_MAX_FIELDS.
Instance Variable max_files Maximum multipart file count; zero rejects all files. Defaults to 32 from HTTP_MAX_FILES.
Instance Variable max_header_size Maximum MIME header bytes per multipart part. Defaults to 16 KiB from HTTP_MAX_PART_HEADER_SIZE.
Instance Variable max_memory_size Budget for retained multipart field strings and in-memory file payloads. Transport buffers, object metadata and temporary copies are additional. Defaults to 8 MiB from HTTP_MAX_MULTIPART_MEMORY_SIZE.
Instance Variable max_part_size Maximum bytes of one multipart file or field. Defaults to 10 MiB from HTTP_MAX_PART_SIZE.
Instance Variable memory_threshold Maximum file payload bytes retained before spooling to disk. Defaults to 256 KiB from HTTP_UPLOAD_MEMORY_THRESHOLD.
