Define a new command using the fluent interface.

Create a command with the given signature and handler. The handler must be a list containing the class and optionally the method name. Validate input types and conventions. Return the created ICommand instance.

Load all command classes and their metadata.

This method loads command metadata from cache if available, otherwise discovers core commands, custom commands, and fluent commands. It then builds Command instances for each command and populates the internal commands dictionary.
