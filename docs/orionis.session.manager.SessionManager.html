class SessionManager: (source)

Constructor: SessionManager(app, cache)

View In Hierarchy

Coordinates the session lifecycle for every HTTP request.

This class is a coordinator only. It never stores session data, never interprets the session payload, and never duplicates logic that belongs to Session or to the backing store.
