class ITransaction(ABC): (source)

Known subclasses: orionis.database.Transaction

View In Hierarchy

Contract for a database transaction usable as an async context manager.

Entering the context begins a transaction (or a savepoint when one is already active); leaving it commits on success and rolls back when an exception escapes the block.

Async Method __aenter__ Begin the transaction and enter the context.
