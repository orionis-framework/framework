class IRelation(IModelQueryBuilder): (source)

Known subclasses: orionis.orm.contracts.belongs_to_many_relation.IBelongsToManyRelation, orionis.orm.relations.Relation

View In Hierarchy

Contract for a query builder bound to a parent model instance.

Every relationship kind (hasOne, hasMany, belongsTo, belongsToMany, and future ones such as polymorphic or through-relations) implements this template so eager loading can drive any of them without knowing its concrete type.

Method addConstraints Constrain the query to the bound parent instance.
Method addEagerConstraints Constrain the query to every parent instance of an eager batch.
Async Method getEager Execute the relationship query assembled for eager loading.
Async Method getResults Execute the relationship query for its bound parent instance.
Method match Group eager-loaded results and attach them to their parents.
