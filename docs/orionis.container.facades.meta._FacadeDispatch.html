class _FacadeDispatch: (source)

Constructor: _FacadeDispatch(cls, name, args, kwargs)

View In Hierarchy

Deferred facade call, awaitable and usable as an async context manager.

Building this object never touches the container; the underlying service is only resolved once the caller either awaits the instance directly (await Facade.method(...)) or enters it with async with Facade.method(...) as value:.
