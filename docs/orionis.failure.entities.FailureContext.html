def __post_init__(self): (source) ¶

Copy bounded metadata and redact values under credential-like keys.

Keep at most 32 entries with string keys and supported scalar values. Truncate keys to 128 characters and string values to 1024 characters. Replace metadata with a read-only mapping of the sanitized entries.
