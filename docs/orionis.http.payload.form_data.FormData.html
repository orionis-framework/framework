class FormData(IFormData): (source)

Constructor: FormData(items)

View In Hierarchy

Hold parsed multipart form fields and uploaded files.

Notes

Stores ordered (name, value) pairs and supports multiple values under the same field name. Implements the context-manager protocol to guarantee all open file handles are released on exit.
