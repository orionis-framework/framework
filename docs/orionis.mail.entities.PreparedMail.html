class PreparedMail: (source)

View In Hierarchy

Carry immutable MIME bytes and a separate validated transport envelope.

Transports consume this value without seeing templates, Mailable classes, storage paths, or a mutable EmailMessage.

recipientsDeduplicated union of To, Cc, and Bcc addresses.
