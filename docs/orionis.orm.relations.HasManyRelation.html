class HasManyRelation(HasOneOrManyRelation[TRelated, Collection[TRelated]]): (source)

Constructor: HasManyRelation(parent, related, foreign_key, local_key)

View In Hierarchy

One-to-many relationship: the related table owns the foreign key.

Mirrors Eloquent's HasMany: the parent owns zero or more related rows (for instance User owning many Post rows), the foreign key living on the related table.

Async Method getResults Retrieve every related row owned by the parent instance.
Method match Attach every matching related row to each parent instance.
