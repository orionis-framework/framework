class Authorizer(IAuthorizer): (source)

Constructor: Authorizer(app)

View In Hierarchy

Answer authorization questions for a given request context.

The authorizer never stores the current identity: every method takes the request context as its first argument. That keeps the service stateless and therefore safe as a container singleton shared by every concurrent request.

Concurrency

Only policy classes are cached. Each evaluation builds a fresh policy in the caller's container scope, so injected request dependencies and mutable policy state are never retained by this singleton.
