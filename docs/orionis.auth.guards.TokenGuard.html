orionis.auth.guards.TokenGuard

class documentation

class TokenGuard(IGuard): (source)

Constructor: TokenGuard(tokens, identities)

View In Hierarchy

Resolve the identity of API requests from a personal access token.

The token travels in the standard header:

Authorization: Bearer <token>

Tokens are opaque, revocable and optionally expiring. No signed payload such as a JWT is involved, so revocation is immediate.

Concurrency

The guard is stateless and safe as a singleton. The only write it performs is the last_used_at update, issued as a single statement where the last writer legitimately wins.
