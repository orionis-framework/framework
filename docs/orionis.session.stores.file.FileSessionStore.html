class FileSessionStore(ISessionStore): (source)

Constructor: FileSessionStore(directory)

View In Hierarchy

Session store that persists each session as a JSON file on disk.

One JSON file per session, named {session_id}.json, stored inside directory. Resolve relative directories when constructing the store and create the directory when it does not exist. Active worker operations finish before caller cancellation propagates; cancellation does not roll back a write or deletion that has already completed.

Expired sessions are evicted lazily during orionis.session.stores.file.FileSessionStore.read, keeping hot-path operations at O(1) complexity. Bulk removal of stale files can be triggered explicitly via orionis.session.stores.file.FileSessionStore.gc.

Notes

The JSON envelope stores id, expires_at and data. Payloads must be JSON-compatible, and expiration is represented as a UTC timestamp.
