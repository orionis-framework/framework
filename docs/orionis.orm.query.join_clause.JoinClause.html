Accumulator of ON conditions for a join declared with a callback.

Handed to the callback form of the join helpers so several ON conditions can be combined, mirroring the fluent join syntax of query builders.

Method __init__ Initialize an empty set of ON conditions.
Method conditions Return the ON conditions collected so far.
