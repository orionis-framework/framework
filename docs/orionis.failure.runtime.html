orionis.failure.runtime

module documentation
(source)

Observe failures only inside an activated application runtime.

Core imports use the standard library and failure entities. Cancelled-work cleanup lazily reuses the shared awaitable utility. Protocols keep ownership of responses, cancellation and recovery.

Class _BorrowedOperation Reuse identical nested metadata without replacing or closing its owner.
