class BootstrapEditor: (source)

Constructor: BootstrapEditor(path, base_path)

View In Hierarchy

Plan surgical Python edits and publish them without clobbering changes.

The editor deliberately does not execute user code. Unsupported or ambiguous construction flows fail before any file is changed.
