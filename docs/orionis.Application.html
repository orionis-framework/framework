orionis.Application

class documentation

class Application(Container, IApplication): (source)

Constructor: Application(*args, **kwargs)

View In Hierarchy

Configure the container and serve requests within one worker event loop.

Notes

Concurrent tasks share kernel initialization and provider startup locks. Mutable application state is not synchronized across threads or event loops. Python and RSGI special methods retain their protocol-defined names.
