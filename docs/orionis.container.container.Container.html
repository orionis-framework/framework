View In Hierarchy

Resolve services from contracts, aliases and constructor signatures.

Concurrency

__new__ is thread-safe: concurrent construction of the same subclass always yields a single instance, guarded by _lock.

Inside one event loop, the one-shot work behind Lifetime.SINGLETON, Lifetime.SCOPED and deferred providers is serialised per key, so concurrent tasks share a single construction instead of duplicating it.

No other guarantee is provided: registration methods mutate plain dictionaries without locks, and containers shared between distinct event loops fall back to per-loop serialisation only.
