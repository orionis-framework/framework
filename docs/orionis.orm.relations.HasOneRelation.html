class HasOneRelation(HasOneOrManyRelation[TRelated]): (source)

Constructor: HasOneRelation(parent, related, foreign_key, local_key)

View In Hierarchy

One-to-one relationship: the related table owns the foreign key.

Mirrors Eloquent's HasOne: the parent is the "one" side (for instance User owning a single Profile), while the foreign key lives on the related table.

Async Method getResults Retrieve the single related row owned by the parent instance.
Method match Attach the first matching related row to each parent instance.
