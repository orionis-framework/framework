Known subclasses: orionis.orm.relations.BelongsToManyRelation

View In Hierarchy

Contract for a many-to-many relationship backed by a pivot table.

Extends IRelation with the pivot-specific operations that have no equivalent on the single-table relationship kinds.

Async Method attach Link the parent to the given related records via the pivot table.
Async Method detach Unlink the parent from the given related records.
Async Method sync Attach exactly the given records, detaching every other one.
Async Method toggle Attach ids not currently linked, detach ids that already are.
Method wherePivot Filter the pivot rows considered by this relationship query.
