class AttributesMixin: (source)

Known subclasses: orionis.orm.Model

View In Hierarchy

Attribute handling behavior shared by every model.

Provides mass assignment with fillable/guarded enforcement, cast application, and serialization helpers. The mixin operates on the _attributes mapping owned by the model instance.
