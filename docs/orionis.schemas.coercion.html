def coerce_payload(payload: object, schema: type[msgspec.Struct], *, enabled: bool = False) -> object: (source) ¶

Prepare marked values and existing structs using copy-on-write containers.

Existing struct constructors and mutations bypass native validation, so expand those instances before the final conversion. Unmarked scalar fields remain strict and schemas without preparation retain their original inputs.

Parameters
payload:objectInput mapping, positional data or existing schema instance.
schema:type[msgspec.Struct]Schema declaring the target types and coercion metadata.
enabled:bool, optionalWhether an enclosing marker enables all descendant fields.
Returns
objectPrepared payload, or the original value when no changes are needed.
