def getAll(self, key: str) -> list[str]: (source) ¶

Return every value for key in insertion order.

Unlike get(), which returns only the last occurrence, this method preserves all values so that repeated parameters such as ?tag=a&tag=b are handled without data loss.

Parameters
key:strThe query parameter name to look up.
Returns
list[str]All values for key in the order they appear in the query string. Returns an empty list when key is absent.
