orionis.orm.query_builder.QueryBuilder

class documentation

class QueryBuilder(IQueryBuilder): (source)

Constructor: QueryBuilder(db_manager, connection_name)

View In Hierarchy

Entry point of the model-less query API, backing the DB facade.

Registered as a singleton, so it never keeps per-query state: every call returns a brand-new object and the connection scope is carried by value. Sharing mutable state here would leak one caller's target connection into every other concurrent request.
