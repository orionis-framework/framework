Define the minimal contract for reading an HTTP request body.

Both stream() and read() must be safe to call multiple times once the body has been fully buffered.

Yield successive byte chunks from the request body.

Implementations must replay from the internal buffer when read() was called first, so streaming consumers (e.g. multipart parsers) still work after a plain body() call.
