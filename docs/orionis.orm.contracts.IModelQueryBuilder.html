class IModelQueryBuilder(IQueryBuilderBase): (source)

Known subclasses: orionis.orm.contracts.relation.IRelation, orionis.orm.query.ModelQueryBuilder

View In Hierarchy

Contract for the query builder bound to a model class.

It inherits the whole query language from orionis.orm.contracts.base_builder.IQueryBuilderBase and only adds what model awareness brings: hydrated results, primary-key lookups, and relationship eager loading.
