orionis.database.Connection

class documentation

class Connection(IConnection): (source)

Constructor: Connection(name, config)

View In Hierarchy

Named database connection encapsulating the SQL engine.

The connection lazily builds its async engine from the Orionis configuration, compiles query plans through orionis.database.SQLCompiler, and exposes only framework-owned types: dictionaries, integers, and result entities. Transactions are task-local and support nesting through savepoints when supported. Redshift uses the official blocking connector through a thread-backed Core engine; it does not support savepoints or returning server-generated identity values.
