Represent a console command and its metadata.

Parameters
objType or class associated with the command.
methodMethod name to invoke on the object. Defaults to 'handle'.
timestampsEnable timestamps for this command. Defaults to True.
signatureCommand usage signature.
descriptionBrief description of the command.
argsDeclarative argument list while the command is being defined, and the parser built from it once the loader materializes the command. Defaults to None.
Returns
CommandInstance containing metadata and configuration for a console command.
