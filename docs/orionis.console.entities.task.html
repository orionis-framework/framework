class Task(BaseEntity): (source)

View In Hierarchy

Represent a scheduled event and configure its execution and timing.

Parameters
signatureUnique identifier for the event.
argsArguments to be passed to the event. Defaults to empty list.
kwargsKeyword arguments to be passed to the event. Defaults to empty dict.
purposeDescription of the event's purpose.
random_delayRandom delay in seconds before triggering.
start_dateDate and time when the event becomes active.
end_dateDate and time when the event becomes inactive.
triggerTrigger mechanism for event execution.
detailsAdditional metadata about the event.
max_instancesMaximum concurrent instances allowed. Defaults to 1.
misfire_grace_timeGrace period in seconds for misfired events.
coalesceWhether to coalesce missed runs into a single run. Defaults to True.
listenersListeners for event-specific logic. Defaults to empty list.
Returns
TaskInstance of Task with specified configuration.
