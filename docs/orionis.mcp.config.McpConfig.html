class McpConfig(BaseEntity): (source)

View In Hierarchy

Bound MCP work and explicitly allow trusted HTTP browser origins.

An absent Origin is accepted by the transport. An empty allowed_origins rejects every present Origin; there is no wildcard or implicit same-origin exception. Each allowed entry is a serialized HTTP(S) origin.
