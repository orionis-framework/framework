orionis.foundation.config.cache.Database

class documentation

class Database(BaseEntity): (source)

View In Hierarchy

Represent the configuration entity for a database-backed cache store.

Mirrors database cache store configuration array, supporting a dedicated connection/table for cache entries and an independent connection/table for the atomic locks used by Cache::lock().

Method __post_init__ Validate the Database cache configuration after initialization.
Method __validateConnection Validate the connection property.
Method __validateDriver Validate the driver property.
Method __validateLockTable Validate the lock_table property.
Method __validateTable Validate the table property.
Instance Variable connection The database connection name used to store cache entries. Resolved from the DB_CACHE_CONNECTION environment variable or None to use the application's default connection.
Instance Variable driver The driver type. Defaults to 'database'.
Instance Variable lock_table The database table name used to store cache locks. Must match the pattern [a-z_]+ when provided. Resolved from the DB_CACHE_LOCK_TABLE environment variable or None to let the driver fall back to its own default.
Instance Variable table The database table name used to store cache entries. Must match the pattern [a-z_]+. Resolved from the DB_CACHE_TABLE environment variable or defaults to 'cache'.
