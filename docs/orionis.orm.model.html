View In Hierarchy

Base class of the Orionis active-record models.

Concrete models declare their columns with the fluent schema types and interact with the database exclusively through the Orionis query builder; the underlying SQL engine never surfaces. Class-level entry points such as where or orderBy start a builder implicitly.

async def save(self) -> bool: (source) ¶

Persist the model, inserting or updating as appropriate.

New models are inserted, receiving their generated primary key; existing models write only their dirty attributes. Timestamps are maintained automatically when enabled, and the saving, creating/updating, created/updated and saved events are dispatched around the write.

boolTrue when the operation succeeds or nothing changed, False when a listener vetoed the write.
