class SessionAuth(BaseEntity): (source)

View In Hierarchy

Represent the configuration of session based authentication.

Only the keys owned by authentication live here. Cookie lifetime, driver and encryption keep their single source of truth in config/session.py.

Method __post_init__ Validate the session authentication options after initialization.
Instance Variable home Path browsers are redirected to once the login succeeds, and the target guest-only pages send already authenticated visitors to.
Instance Variable key Session key holding the identifier of the authenticated identity.
Instance Variable redirect_to Path browsers are redirected to when authentication is required. None renders the standard 401 error response instead.
