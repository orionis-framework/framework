class _ScanBuffers: (source)

Constructor: _ScanBuffers()

View In Hierarchy

Collect mutable scan buckets for ReflectionConcrete._scanClass.

Store all classification buckets in one object so type-specific routing helpers can run from a flat loop without passing many separate containers. __slots__ avoids per-instance __dict__ allocations and keeps attribute access fast.
