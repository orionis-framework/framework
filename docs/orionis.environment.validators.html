Validate that the provided environment variable name meets requirements.

Notes

Pure function — safe to cache with lru_cache. After the first call per unique key, validation is an O(1) dict lookup instead of a regex match.

Parameters
key:strThe environment variable name to validate.
Returns
strThe validated environment variable name if it meets format requirements.
Raises
TypeErrorIf the provided key is not a string.
ValueErrorIf the key does not match the required format (must start with an uppercase letter and contain only uppercase letters, digits, or underscores).
