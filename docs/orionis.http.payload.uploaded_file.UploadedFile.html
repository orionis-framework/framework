def _sanitizeFilename(filename: str) -> str: (source) ¶

Return a safe version of filename suitable for use on the filesystem.

Strips null bytes, control characters, path separators, and Windows-reserved characters. Removes leading dots to prevent dotfile or path-traversal attacks. Falls back to "upload" when the sanitized result is empty.

def __init__(self, filename: str, content_type: str | None, memory_threshold: int = 1024 * 1024): (source) ¶

Initialize a new UploadedFile for an incoming multipart part.

The filename is sanitized on ingestion: control characters, path separators, and Windows-reserved characters are stripped, and path-traversal sequences (leading dots) are removed. If the result is empty after sanitization the filename falls back to "upload".
