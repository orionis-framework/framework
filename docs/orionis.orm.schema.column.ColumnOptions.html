class ColumnOptions: (source)

View In Hierarchy

Secondary, type-specific knobs mirroring SQLAlchemy constructor args.

A single options object keeps ColumnDefinition constructible with a handful of parameters while still exposing every keyword that the equivalent SQLAlchemy Core type accepts, one attribute per keyword.
