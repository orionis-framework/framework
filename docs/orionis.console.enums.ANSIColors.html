class ANSIColors(Enum): (source)

View In Hierarchy

Define ANSI escape codes for styling terminal text and backgrounds.

This Enum provides ANSI escape codes for foreground and background colors, as well as text styles such as bold, underline, dim, italic, and magenta. Use these codes to enhance console output readability and emphasis.

Returns
strThe ANSI escape code string for the selected color or style.
