def _configure_mysql_binary_parameters(dbapi_connection: object): (source) ¶

Install safe binary conversion on one adapted aiomysql connection.

PyMySQL 1.2.3 keeps escape_bytes_prefixed as a noncallable import alias; aiomysql 0.3.2 calls that alias for every bytes parameter. Hex literals keep binary storage working without downgrading PyMySQL or patching its modules.

Parameters
dbapi_connection:objectSQLAlchemy DBAPI adapter exposing its underlying driver connection.
Returns
NoneReplace only this connection's binary escape path when available.
