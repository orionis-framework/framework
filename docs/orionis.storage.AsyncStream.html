class AsyncStream(IStorageStream): (source)

Constructor: AsyncStream(opener, on_close)

View In Hierarchy

Asynchronous wrapper around a lazily opened binary handle.

The underlying handle is produced by opener on first use (or on __aenter__) and every blocking operation is executed on a worker thread, keeping the event loop responsive. Drivers may provide an on_close callback to persist buffered data before the handle is released.

Async Method __aenter__ Open the underlying handle and return the stream.
Async Method __aexit__ Close the stream when leaving the async context.
Async Method __ensureHandle Open the underlying handle on first use and return it.
