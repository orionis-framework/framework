async def __preloadHandlers(self): (source) ¶

Import route handlers and prepare their dependency metadata at boot time.

Populates two int-keyed dispatch tables using route object identity, eliminating per-request module imports, attribute lookups, and tuple key construction from the handler invocation hot path. View routes are stored in a third table holding only their template name. Ordinary constructor and action plans are prepared without resolving services or creating controller instances. Custom descriptors remain lazy.

Returns
NoneUndocumented

Pre-build middleware instances for all routes at boot time.

Iterate every compiled route and eagerly resolve each middleware class through the container. Results are stored keyed by the immutable stack tuple so identical stacks share the same instances.
