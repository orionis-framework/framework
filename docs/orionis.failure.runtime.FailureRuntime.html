def createTask(self, coroutine: object, *, name: str | None = None) -> asyncio.Task: (source) ¶

Create and supervise application work until shutdown.

During shutdown, cancel new work before entering its awaitable. Valid activation or startup reopens admission after cleanup. If scheduling fails, close only the runtime wrapper; the original remains caller-owned. Adopted futures on the running loop remain owned until cancellation cleanup completes, without cancelling an already unwinding task again.

Parameters
coroutine:objectAwaitable application work whose failures must be observed.
name:str or None, optionalTask name and operation label for failure observation.
Returns
asyncio.TaskSupervised task registered for cancellation during runtime shutdown.
Raises
RuntimeErrorIf no event loop is running.

async def shutdown(self, *, exclude: asyncio.Task | None = None): (source) ¶

Cancel owned application tasks and drain their failure reports.

Exclude the current task and return immediately from a reporting callback or adopted cleanup task to avoid self-deadlock. Concurrent callers share one cleanup task; cancelling a waiter does not cancel that cleanup. Keep admission closed until a subsequent valid activation or startup.

Parameters
exclude:asyncio.Task or None, optionalLifecycle owner awaiting this cleanup from another task. Exclude it to avoid cancelling and waiting on the task that owns this shutdown.
Returns
NoneNo return value.
