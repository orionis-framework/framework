Known subclasses: orionis.auth.context.AuthenticationContext

View In Hierarchy

Define the authenticated state bound to a single request.

The context is never stored on a singleton. It lives in the container scope opened by the HTTP kernel, so two concurrent requests can never observe each other's identity.
