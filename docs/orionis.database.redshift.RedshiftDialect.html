class RedshiftDialect(RedshiftConnectorDialect): (source)

View In Hierarchy

Retain the connector dialect without PostgreSQL-only capabilities.

Amazon Redshift does not implement DML RETURNING or PostgreSQL sequences. Server-generated IDENTITY values are not returned by the connector; callers needing a model key immediately must provide a client-generated primary key. This module is imported only when a Redshift engine is first constructed.
