class S3StorageDriver(IStorageDriver): (source)

Constructor: S3StorageDriver(config)

View In Hierarchy

Storage driver backed by Amazon S3 (or S3-compatible services).

Uses the official AWS SDK for Python (boto3), which is an optional dependency: it is not installed with the framework. Install it before using this driver:

uv add 'orionis[s3]'

The SDK is imported lazily on first operation, and every blocking call runs on a worker thread via asyncio.to_thread so the event loop stays responsive. Directories are virtual: prefixes are inferred from object keys, and explicit directories are stored as zero-byte path/ marker objects.
