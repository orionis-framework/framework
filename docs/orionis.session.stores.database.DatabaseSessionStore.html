orionis.session.stores.database.DatabaseSessionStore

class DatabaseSessionStore(ISessionStore): (source)

Constructor: DatabaseSessionStore(connection, table)

View In Hierarchy

Session store that persists each session as a row in a database table.

Mirrors orionis.cache.stores.database.DatabaseCacheBackend: records live in a dedicated table (id / payload / expires_at) resolved through the session.connection configuration, using upsert-by-retry semantics so no dialect-specific ON CONFLICT syntax is required.

Unlike the cache backend, a plain SQL table has no native TTL, so expired rows are evicted lazily on read and can be swept in bulk via gc.
