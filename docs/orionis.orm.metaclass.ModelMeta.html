class ModelMeta(type): (source)

Constructor: ModelMeta(name, bases, namespace, **kwargs)

View In Hierarchy

Metaclass discovering model columns and building their metadata.

At class creation time the metaclass collects column definitions (including inherited ones), removes them from the class namespace so instance attribute access reaches the attribute store, derives the table name and primary key, and precompiles cast handlers.
