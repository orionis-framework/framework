class OracleZonedTimestamp(TypeDecorator[datetime]): (source)

View In Hierarchy

Bind and read Oracle TIMESTAMP WITH TIME ZONE values in UTC.

The driver binds Python datetimes without their offsets and returns timestamps without timezone metadata.

Method _bindExpression Attach the UTC offset explicitly to each bound Oracle timestamp.
Method _bindValue Normalize an input instant before the driver discards its offset.
Method _columnExpression Extract the UTC instant before the driver decodes an Oracle timestamp.
