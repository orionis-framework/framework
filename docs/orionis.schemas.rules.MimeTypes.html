class MimeTypes(Rule): (source)

Constructor: MimeTypes(*mime_types, message)

View In Hierarchy

Ensure an uploaded file declares one of the accepted MIME types.

Wildcard subtypes such as "image/*" match every subtype of the given top-level type.

Method __init__ Initialize the rule with the accepted MIME types.
