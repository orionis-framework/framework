# Data encryption

Encryption lets you recover sensitive text using a stable application key. Choose a format and plan key custody before storing the first tokens.

## Learning path

1. [Protecting and recovering application values](encrypting-values.md): prerequisites, progressive usage, configuration, integration, failures, and public reference.

Isolated examples use minimal application objects; facades require an initialized Orionis application and its providers. Source and contracts determine the documented capabilities.
