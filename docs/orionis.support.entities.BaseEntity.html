Provide a shared constructor, serialization and dataclass metadata.

Notes

Use @dataclass(init=False) on each subclass that should inherit the shared constructor. It accepts only keyword arguments for ordinary fields and public extra attributes; InitVar parameters are not supported. Extras require an instance dictionary, normally provided by slots=False.

Fields marked init=False cannot be supplied by the caller. Their defaults are initialized, or __post_init__ must set them when no default exists. Subclasses are responsible for type validation.

Return a recursively copied dictionary of declared and extra values.

Notes

Unlike dataclasses.asdict, nested entities include their own public extra attributes. Enum members are replaced by their values, including inside dictionaries, lists and tuples. Declared private fields are included; private extra attributes are not.

This method does not encode JSON or support cyclic entity or container graphs.
