orionis.orm.ConnectionResolver

class ConnectionResolver: (source)

View In Hierarchy

Static bridge between the ORM and the database connection manager.

The database service provider installs the manager here during boot; models and query builders resolve their connections through this class without ever touching the container or the SQL engine.
