class Session(BaseEntity): (source)

View In Hierarchy

Configure the session middleware.

Parameters
driverSession driver. Defaults to SessionDriver.MEMORY.
lifetimeSession lifetime in minutes. Defaults to 120.
expire_on_closeExpire session on browser close (omits Max-Age). Defaults to False.
track_previous_urlRemember successful navigation URLs in the session. Defaults to True.
renewal_intervalMinimum seconds between renewal writes for unchanged scalar payloads. Zero renews every request. Must be strictly below the lifetime in seconds so renewal can occur while the session is still valid. Mutable payloads and dirty sessions are always persisted.
filesPath to session files (file driver). Defaults to 'storage/framework/sessions'.
connectionDatabase connection for session storage (database driver). Defaults to None.
tableDatabase table for session storage (database driver). Defaults to 'sessions'.
cacheCache store for session storage (cache driver). Defaults to None.
cookieName of the session cookie. Defaults to 'sessionid'.
pathCookie path. Defaults to '/'.
domainCookie domain for cross-subdomain usage.
secureRestrict cookies to HTTPS. Defaults to False.
http_onlyPrevent JavaScript from accessing the cookie. Defaults to True.
same_siteSameSite cookie policy. Defaults to SameSitePolicy.LAX.
partitionedEnable CHIPS (partitioned) cookies. Defaults to False.

def __validateDriver(self): (source) ¶

Normalise and validate the driver field.

Accept a SessionDriver enum member or a plain string matching a recognised driver name (case-insensitive). When a valid string is supplied it is coerced to the corresponding SessionDriver member via object.__setattr__.
