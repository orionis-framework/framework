View In Hierarchy

Enumerate standard logging levels.

This enumeration provides standard logging levels used throughout the logging module.

Returns
LevelThe enumeration member representing a logging level.
Constant CRITICAL A very serious error, indicating that the program itself may be unable to continue running. Value is 50.
Constant DEBUG Detailed information, typically of interest only when diagnosing problems. Value is 10.
Constant ERROR Due to a more serious problem, the software has not been able to perform some function. Value is 40.
Constant INFO Confirmation that things are working as expected. Value is 20.
Constant WARNING An indication that something unexpected happened, or indicative of some problem in the near future. Value is 30.
