class SeederRunner: (source)

Constructor: SeederRunner(app, conn_manager)

View In Hierarchy

Apply new seeders exactly once on the selected database connection.

Files under database/seeders are discovered in lexical filename order. The application container builds each seeder so constructors can receive dependencies. Each seeder and its tracking row commit in the same transaction. The unique tracking key acts as a database-level claim when runs overlap.
