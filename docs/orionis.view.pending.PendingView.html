class PendingView: (source)

Constructor: PendingView(engine, template, context)

View In Hierarchy

Awaitable, chainable result of IViewFactory.make.

Rendering is deferred until the object is awaited, so response mutators such as withInput(), withErrors(), withFlash() or withCookie() can be chained directly on the make() call:

return await View.make("auth.login").withErrors(errors)

Every attribute that exists on HTMLResponse is accepted and replayed on the real response once the template has been rendered.
