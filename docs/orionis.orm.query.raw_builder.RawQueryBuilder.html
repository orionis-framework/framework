class RawQueryBuilder(QueryBuilderBase, IRawQueryBuilder): (source)

Constructor: RawQueryBuilder(table)

View In Hierarchy

Fluent query builder over a plain table name.

Unlike orionis.orm.query.builder.ModelQueryBuilder, it is not bound to a Model: rows are returned as plain dictionaries and the target table carries no declared schema, so the SQL compiler declares each referenced column lazily. Built by orionis.orm.db.DB.table.

Every clause method comes from QueryBuilderBase, the same engine model queries run on, so both entry points speak exactly the same query language and compile through the same pipeline.
