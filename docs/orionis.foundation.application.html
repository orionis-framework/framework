async def _asgi_receive_dispatcher(receive: Callable[[], Awaitable[dict[str, Any]]], request_queue: asyncio.Queue, handler_task: asyncio.Task) -> bool: (source) ¶

Consume ASGI receive messages and dispatch them concurrently.

Forward body chunks through a bounded queue and cancel the handler when the receive channel reports a disconnect or fails. A full queue pauses receive calls until the handler consumes a buffered message.

Parameters
receive:Callable[[], Awaitable[dict[str, Any]]]ASGI receive callable provided by the server.
request_queue:asyncio.QueueQueue that buffers body messages for the handler.
handler_task:asyncio.TaskKernel task to cancel when the receive channel closes.
Returns
boolWhether the disconnect requested cancellation of the handler.
