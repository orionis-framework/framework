View In Hierarchy

Represent an awaitable, chainable template rendering result.

Created by orionis.view.contracts.factory.IViewFactory.make.

Rendering is deferred until the object is awaited, so response mutators such as withInput(), withErrors(), withFlash() or withCookie() can be chained directly on the make() call:

return await View.make("auth.login").withErrors(errors)

Callable attributes on orionis.http.HTMLResponse are accepted and replayed on the real response once the template has been rendered. Initial response options are applied before queued mutations, in call order.
