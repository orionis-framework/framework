def fallback(self, action: RouteAction): (source) ¶
overridden in orionis.http.routes.router.Router

Register the fallback handler for unmatched routes (HTTP 404).

Only one fallback may be registered; a second call raises FallbackRouteAlreadyRegisteredException.

Parameters
action:RouteActionCallable, invokable controller class (defining __call__), or [ControllerClass, 'method_name'] list. Required because fallback registration does not return a fluent route builder.
Returns
NoneThe fallback is stored on the instance; no value is returned.
Raises
FallbackRouteAlreadyRegisteredExceptionIf a fallback handler has already been registered.
TypeErrorIf the action is None or is not an accepted handler form.
ValueErrorIf a controller pair has an invalid length or names a missing method.
