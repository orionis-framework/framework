class TranslationRepository(ITranslationRepository): (source)

Constructor: TranslationRepository(loader)

View In Hierarchy

In-memory cache of translation maps keyed by locale.

Each locale is loaded from disk exactly once; every subsequent lookup resolves from the internal dictionary with O(1) access. The cache is fully transparent to consumers.

Notes

The repository uses no lock. Two tasks missing the cache for the same locale may both call the loader; the last assignment wins and both callers receive a valid map. get returns the cached mapping itself, not a copy, so mutating it mutates the cache for every consumer.
