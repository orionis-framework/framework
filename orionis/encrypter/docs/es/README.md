# Cifrado de datos

El cifrado permite recuperar texto sensible usando una clave de aplicación estable. Elige el formato y planifica la custodia de esa clave antes de almacenar los primeros tokens.

## Recorrido

1. [Proteger y recuperar valores de aplicación](encrypting-values.md): requisitos, uso progresivo, configuración, integración, errores y referencia pública.

Los ejemplos aislados usan objetos de aplicación mínimos; las facades requieren una aplicación Orionis inicializada y sus providers. El código fuente y los contratos determinan las capacidades descritas.
