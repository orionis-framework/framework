class LocalStorageDriver(IStorageDriver): (source)

Constructor: LocalStorageDriver(root, base_url)

View In Hierarchy

Storage driver backed by the local filesystem.

Every path is resolved inside the configured root directory and all blocking I/O runs on worker threads via asyncio.to_thread, keeping the event loop responsive. Visibility is mapped onto POSIX permission bits (0o644/0o600 for files), which degrades gracefully on platforms without a full POSIX mode implementation.
