Determine whether a path is static or dynamic and compile its regex.

This method is intentionally public so that RouteCache can call it during cache deserialisation to reconstruct regex and converters without ever persisting callable objects.

Parameters
path:strThe route path, e.g. '/users/{id:int}'.
Returns
tuple[bool, re.Pattern | None, dict[str, Callable]](is_static, regex, converters) — regex and converters are None / empty for static paths.
