def __computeSourcesHash(self) -> str: (source) ¶

Compute and return a hash representing the state of monitored sources.

This method generates a SHA-1 hash based on the modification time and size of all monitored files and Python files in monitored directories, excluding the cache file itself. The hash is cached for a short interval to avoid redundant computation.

Returns
strThe computed SHA-1 hash as a hexadecimal string.
