class SQLCompiler: (source)

Constructor: SQLCompiler(prefix, driver)

View In Hierarchy

Translate Orionis query plans into engine-executable statements.

This is the only component, together with the connection and the dialect helpers, aware of the underlying SQL toolkit. It converts TableDefinition objects into engine table metadata (cached per compiler) and query plans into executable statements.
