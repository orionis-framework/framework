class IQueryBuilderBase(ABC): (source)

Known subclasses: orionis.orm.contracts.IModelQueryBuilder, orionis.orm.contracts.raw_builder.IRawQueryBuilder

View In Hierarchy

Contract of the query language shared by every Orionis builder.

It declares the fluent clause surface (projection, conditions, joins, grouping, ordering, paging, locking, unions) and the terminals whose result does not depend on how rows are represented. Model-bound and model-less builders both honor it, which is what guarantees DB.table(...) and Model.query() speak the same language.
