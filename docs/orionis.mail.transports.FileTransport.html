class FileTransport(IMailTransport): (source)

View In Hierarchy

Publish complete private .eml files atomically without overwriting.

Publication requires hard-link support in the target filesystem, such as NTFS on Windows or a regular local POSIX filesystem; unsupported filesystems fail explicitly. Each worker owns its temporary file and never shares per-message state.
