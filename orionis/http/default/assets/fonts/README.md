# Bundled fonts

These original typefaces are bundled so the default pages make no external font
requests. Each family is licensed under the SIL Open Font License 1.1. See the
corresponding `*-OFL.txt` file in this directory.

Downloaded from the upstream Google Fonts repository on 2026-09-23:

- `orbitron.ttf`: https://github.com/google/fonts/blob/main/ofl/orbitron/Orbitron%5Bwght%5D.ttf
- `share-tech-mono.ttf`: https://github.com/google/fonts/blob/main/ofl/sharetechmono/ShareTechMono-Regular.ttf
- `fira-code.ttf`: https://github.com/google/fonts/blob/main/ofl/firacode/FiraCode%5Bwght%5D.ttf

Orbitron and Fira Code are variable TrueType fonts. Share Tech Mono is a regular
TrueType font. System font fallbacks remain available when web fonts are disabled.
