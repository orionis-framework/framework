Dispatch to _ENCODE_EXACT for known types via O(1) hash lookup; fall back to fast-path dict/list handling, then _encode_subclass for all remaining cases.

Encode subclass instances not covered by the exact-type dispatch table.

Walk a priority-ordered chain of isinstance checks to handle Path subclasses, datetime hierarchy, collection subclasses, and sentinel values. Raises TypeError for unsupported types.
