class RealtimeConfig(BaseEntity): (source)

View In Hierarchy

Configure finite per-connection RPC budgets and broadcast concurrency.

Stream lifetimes are unlimited unless their invoke envelope supplies a timeout. Ordinary invocations use invocation_timeout; client-result calls use client_result_timeout. Neither limits connection lifetime.
