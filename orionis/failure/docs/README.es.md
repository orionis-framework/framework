# Gestión de excepciones

El módulo de fallos usa dos hooks de aplicación, `handleFailure` y `handleResult`, para definir el logging y la presentación diferidos de cada incidente. El manual explica el contrato, la personalización, los límites del inicio y la migración desde los métodos eliminados del handler.
