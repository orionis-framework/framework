class ModelQueryBuilder(QueryBuilderBase, IModelQueryBuilder): (source)

Known subclasses: orionis.orm.relations.Relation

Constructor: ModelQueryBuilder(model)

View In Hierarchy

Fluent query builder bound to a model class.

It adds model awareness on top of QueryBuilderBase: rows are hydrated into model instances, written values go through the declared casts, timestamps are maintained, and relationships can be eager loaded. The query language itself is entirely inherited, so a model query and a DB.table(...) query compile identically.
