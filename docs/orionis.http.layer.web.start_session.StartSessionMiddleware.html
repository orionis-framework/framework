def __storeCurrentUrl(request: Request, response: Response, session: ISession): (source) ¶

Record the current URL as the page to redirect back to.

Only GET/HEAD responses with status 200-299 are stored, excluding AJAX and requests that want JSON. Other statuses, background calls and form submissions never overwrite the previous page.
