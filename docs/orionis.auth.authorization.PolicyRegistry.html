class PolicyRegistry: (source)

Constructor: PolicyRegistry()

View In Hierarchy

Map resource classes to the policy classes protecting them.

Lookups walk the method resolution order once and memoise the result, so an inherited policy costs a single dictionary read after the first request that needed it.

Concurrency

Registration happens during application boot. The lookup cache is a pure function of the registry, so a concurrent first lookup may compute the same value twice without any observable difference.
